# 별이 죽는 속도로 너를 읽는다
**CHRONO-ELEGY : 0.0004Hz — 영원관측기구 제0기록보존실**

> *「이 수첩을 여는 순간, 너는 일곱 번 죽은 나를 여덟 번째로 살해하게 된다. ——백시현」*

## 실행 방법
1. 폴더 내 **`게임 실행.bat`** 파일을 더블클릭하면 브라우저에서 즉시 실행됩니다.
2. 또는 터미널에서 아래 명령어로 실행할 수 있습니다:
   ```bash
   npm run dev      # 개발 서버 (http://localhost:5173)
   npm run preview  # 프로덕션 빌드 서버 (http://localhost:4173)
   ```

## 작품 구성 및 특징
- **정통 장편 비주얼·라이트 노벨 서사**: 프롤로그 ~ 종장(전 6부, 총 20개 세계선 씬, 550+ 시네마틱 비트, 멀티 루트 & 4종 결말)
- **하이브리드 ADV / NVL 연출 시스템**: 캐릭터 스탠딩 대화 모드(ADV)와 문학 전면 서술 모드(NVL), 챕터 타이틀 카드, 인라인 루비(Ruby) 주석 및 실시간 세계관 용어 팝오버(`[[용어]]`) 지원
- **직접 제작된 오리지널 비주얼 에셋**:
  - 와이드스크린 배경 아트워크 8종
  - 표정 변화가 완벽히 정렬된 투명 크로마키 캐릭터 스탠딩 일러스트 10종 (세라, 연하린, 유리우스, 노엘)
  - 핵심 서사 풀스크린 이벤트 CG 7종 (타이틀 클리어 후 해금되는 봄의 시리우스 플랫폼 변화 포함)
- **직접 작곡·합성한 8곡의 오리지널 사운드트랙 (OST) & 프로시저럴 효과음 엔진**:
  - 피아노, 첼레스타, 현악 앙상블, 파이프 오르간, 일렉트로닉 퍼커션을 콘서트홀 리버브로 렌더링한 8곡의 테마곡 및 음악 감상실 수록
- **완전한 편의 시스템**: 세계선 인과율 분기도(Flowchart 시간 도약), 12슬롯 세이브/로드 + 자동 저장 + 퀵세이브(`F5`)/퀵로드(`F9`), 지문 회상록(`L`/마우스 휠↑), 천문 기록원(세계관 백과사전 20항목 · CG 갤러리 · 음악실 · 결말 기록부)
